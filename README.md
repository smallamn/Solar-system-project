# Solar-system-project

A simple **2D planetary motion simulator** written in Python using `tkinter`.

## Features
- N-body gravitational simulation (scaled for visualization)
- Sun + multiple planets with continuous motion
- Orbital trails
- Pause/Resume and Reset controls
- Adjustable simulation speed

## Run
```bash
python3 planetary_simulator.py
```

## Controls
- `Space`: pause/resume
- `R`: reset the system
- Speed slider: slow down or speed up simulation
